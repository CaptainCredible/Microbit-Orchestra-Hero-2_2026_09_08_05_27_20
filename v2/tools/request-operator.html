Become a highscore operator

Operators run micro:bit Orchestra Hero at their own school, library or event, and send the players' scores to the global highscore list. Ask for access here. Once the admin has approved it, sign in on the game's highscores page with the same email and password.

This page is not connected to a highscore database yet (FIREBASE_CONFIG in config.js is empty).

Check your spam folder. The mail comes from noreply@mbohscores.firebaseapp.com, which mail providers often treat as junk. Searching for mbohscores finds it faster than scrolling.

Use the newest email only. Sending it again makes the previous link stop working - an older one will say it has expired or been used already. It also helps to move the mail out of spam before clicking, since some providers follow links in junk mail to check them, and that uses the link up before you get there.

You will get an email when it is approved. It comes from the admin personally, not from the game, so look out for a normal message rather than anything automatic - and check your spam folder, since a first message from an unfamiliar address often lands there. There is no set waiting time; a person has to read your request. You can also come back to this page at any time and it will tell you where things stand.
