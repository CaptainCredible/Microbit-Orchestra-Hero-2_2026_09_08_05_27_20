// ============================================================================
// sound-settings.txt - the reference copy, annotated. A real one is whatever
// the sound panel gave you, pasted straight in.
//
// How to make one:
//   1. DEBUG_SOUND = true in config.js, or press "d" while the app is running
//   2. pick this song and move the sliders until it sounds right
//   3. press "export settings"
//   4. paste the whole block over this file
//
// No reformatting and no picking bits out: what the panel exports is exactly
// what is read back. The `const SOUND_DEFAULTS = ` around it and the trailing
// semicolon are expected, and // comments and trailing commas are allowed on
// top of that - so notes to yourself survive until the next export.
//
// Anything left out uses the default from config.js, so a file with nothing
// but a `keys` block is perfectly good - see breakbeat/sound-settings.txt.
// Each song starts from the defaults, never from whatever the song before it
// left behind, so leaving something out really does mean "the normal one".
//
// The whole block is below with every setting in it, as a reference for what
// can be set. These are the defaults, so as written this file changes nothing.
// ============================================================================

    //

    // of the whole mix. PAD_VOICES in config.js is the knob if a slow machine
    // struggles, since the cost is per sounding voice.

    level: 0.5,
